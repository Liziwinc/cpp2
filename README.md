Консольное приложение для учета и управления различными типами железнодорожных вагонов.

### Особенности реализации:
- **Иерархия классов:** Реализовано глубокое наследование от базового класса `ALL` к специализированным классам: `SV`, `Restaurant`, `Coupe`, `Cargo`.
- **Виртуальные методы:** Использование `virtual` функций для реализации специфического поведения каждого типа вагона (например, услуги в ресторане vs погрузка в товарный вагон).
- **Управление коллекцией:** Использование кастомного вектора для динамического хранения объектов разных классов.

### Бизнес-логика:
- Продажа билетов с автоматическим расчетом выручки и проверкой наличия свободных мест.
- Система обслуживания пассажиров (разнос чая, объявления).
- Учет специфических характеристик: тип питания в ресторанах, количество комнат в купе.
